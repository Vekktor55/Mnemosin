# Запуск «МНЕМОСИН» на своём ПК

Срез: после промпта **1.5** (шина событий, outbox-публикатор, журнал хода, фоновые джобы). Дата: 2026-10-13.

## 1. Требования

| Что     | Нужно                                          | Комментарий                                                                                                                                                                                          |
| ------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node.js | **22 LTS+** (`engines: >=22.0.0`, `.nvmrc`)    | На 20.20.2 тоже работает, но см. `docs/ARCHITECTURE.md` D195: `better-sqlite3` на Node 20 в этой среде падал, поэтому БД — **libsql**. На Node 22 можно вернуться на `better-sqlite3`, если захотите |
| npm     | 10+                                            | воркспейсы (`shared/*`, `core`, `modules/*`, `infrastructure/*`, `gateways/*`, `apps/*`, `client`)                                                                                                   |
| Сеть    | только для `npm install`                       | Внешние AI/ComfyUI-ключи **не нужны**: весь цикл офлайн                                                                                                                                              |
| ОС      | Linux / macOS / Windows (WSL предпочтительнее) | Нативный бинарник libsql есть под все три платформы                                                                                                                                                  |

Компилятор C++ **не требуется** — все нативные зависимости ставятся prebuild-бинарниками.

## 2. Команды

```bash
tar -xzf mnemosin-snapshot-1.6.tar.gz && cd mnemosin

node --version                       # ожидаем v22.x
npm install                          # ~1–2 мин, сеть нужна только здесь

cp .env.example .env
# заполнить ОБЯЗАТЕЛЬНО:
#   JWT_SECRET  — минимум 32 символа, сгенерировать:
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
#   DATABASE_URL=file:./data/mnemosin.sqlite

npm run db:migrate                   # создаст data/mnemosin.sqlite, 17 таблиц / 26 индексов
npm run dev                          # http://localhost:3000/health
```

Проверка в другом терминале:

```bash
curl -s localhost:3000/health | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log(JSON.stringify(JSON.parse(s),null,2)))"
```

Ожидаемо: `{"ok":true,"version":"...","capabilities":{...}}`.

Играть пока нечем — это слой «фундамента».

## 5. Перенос кода на свой ПК

Репозиторий живёт в песочнице, `git history` между сессиями не сохраняется. Поэтому каждый срез упаковывается в архив:

```
mnemosin-snapshot-<промпт>.tar.gz   # без node_modules, dist, .env, *.sqlite
```

В архиве 346 файлов, ~530 КБ. На своём ПК: распаковать → `npm install` → заполнить `.env` → команды из §2.

Чтобы забрать свежий срез — скажите «собери архив» (или «собери архив после 1.6»).
