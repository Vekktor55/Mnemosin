## 3. Правила зависимостей

```text
shared/contracts   ← не зависит ни от кого (только zod)
        ↑
      core           ← только contracts (запрещены: fastify, drizzle, better-sqlite3, pino, провайдерские SDK)
        ↑
    modules/*        ← contracts + core; НЕ импортируют infrastructure и друг друга (D161)
        ↑
infrastructure/*     ← contracts + core/domain/ports (только порты, не сервисы ядра)
gateways/*           ← contracts + modules (команды); никакой доменной логики (инвариант 14)
        ↑
   apps/server       ← wiring: modules-registry, bootstrap, main
client               ← только contracts
```

Контроль (промпт 1.3): `dependency-cruiser` + `eslint no-restricted-imports` + `tests/arch/*` (включая хэш-манифест `core/`, который доказывает неизменность ядра при добавлении провайдера или модуля — критерии A1.14, A3.5).

## 5. Как проверять

```bash
npm install
npm run typecheck     # tsc -b (сборка + проверка типов всех пакетов)
npm run lint          # eslint + prettier --check
npm test              # vitest: unit/integration/arch/contract
npm run dev           # сервер на :3000 (нужен .env с JWT_SECRET и DATABASE_URL)
npm run verify:stage1 # приёмка этапа 1: таблица A1.1–A1.16
```

Перед `npm run dev`: `cp .env.example .env` и заполнить `JWT_SECRET`
(`node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`) и `DATABASE_URL`.
